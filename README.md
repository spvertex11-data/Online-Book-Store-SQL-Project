📚 Online Book Store SQL Project

## 📌 Overview

The Online Book Store SQL Project is a complete SQL database project built using three relational datasets: Books, Customers, and Orders.

## Project Architecture

Online Book Store
│
├── Books.csv
│      │
│      ├── Book_ID
│      ├── Title
│      ├── Author
│      ├── Genre
│      ├── Published Year
│      ├── Price
│      └── Stock
│
├── Customers.csv
│      │
│      ├── Customer_ID
│      ├── Name
│      ├── City
│      └── Country
│
└── Orders.csv
       │
       ├── Order_ID
       ├── Customer_ID
       ├── Book_ID
       ├── Quantity



## 🚀 Project Objectives

- Design relational database
- Import CSV datasets
- Perform SQL analysis
- Solve business problems
- Generate business insights

## 📈 Business Problems Solved

### Basic Queries

- Fiction Books
- Books after 1950
- Canadian Customers
- November Orders
- Total Stock
- Most Expensive Book
- Quantity > 1 Orders
- Orders Above $20
- Available Genres
- Lowest Stock
- Total Revenue

### Advanced Queries

- Books Sold by Genre
- Average Fantasy Price
- Customers with Multiple Orders
- Most Ordered Book
- Top Fantasy Books
- Quantity Sold by Author
- High Spending Cities
- Highest Spending Customer
- Remaining Stock
