📚 Online Book Store SQL Project

## 📌 Overview

The Online Book Store SQL Project is a complete SQL database project built using three relational datasets: Books, Customers, and Orders.

## Project Architecture

Online Book Store
│
├── Books.csv
│      │
│      ├── Book_ID
│      ├── Title
│      ├── Author
│      ├── Genre
│      ├── Published Year
│      ├── Price
│      └── Stock
│
├── Customers.csv
│      │
│      ├── Customer_ID
│      ├── Name
│      ├── City
│      └── Country
│
└── Orders.csv
       │
       ├── Order_ID
       ├── Customer_ID
       ├── Book_ID
       ├── Quantity
       ├── Order_Date
       └── Total_Amount
